Coverage

Ten asset classes. One normalized model.

Every module discovers, tests and validates against the OWASP standard it's measured by, then feeds one findings model — deduplicated, correlated and risk-scored once.

01

Web applications

Crawl (incl. headless SPA), OWASP Top-10 active checks, injection fuzzing (SQLi/XSS/SSTI/XXE/…), safe exploit validation.

02

REST & GraphQL APIs

Two-identity BOLA/IDOR diffing, BFLA, mass-assignment, JWT alg:none, tenant confusion — the OWASP API Top 10.

03

Mobile — APK & IPA

Native static analysis (no external mobile-analysis engine needed): manifest flags, exported components, ATS, secrets, debug-signing — mapped to MASVS/MASTG.

04

Desktop binaries

PE/ELF/Mach-O hardening, code-signing, Electron .asar misconfig, container unpacking — all without external parsing libraries.

05

Infrastructure

Host/service discovery with automatic service-banner → CVE mapping, ranked by exploit pressure.

06

Active Directory

Directory attack-path analysis: Kerberoast, delegation, DCSync, and computed paths to Domain Admin — not just a config checklist.

07

WordPress

Native fingerprint, version & user enumeration, exposed config/backup files; external WordPress & template-based scanning engines layer on when present.

08

Network devices & firewalls

Config hygiene, insecure services and management-plane exposure against CIS-style baselines.

09

OS hardening

CIS-style baseline review from a policy export — no live access required.

10

Cloud, container & IaC

Container/IaC image scanning, Kubernetes CIS checks, cloud-posture (CSPM) analysis — mapped to CIS/PCI/NIST and prioritized.

What makes it a pentest, not a scan

Depth where a real engagement lives.

Active engine

Test, then prove it

A native active-testing engine — not a wrapper. Blind-injection fuzzer with boolean/time/out-of-band detection, a self-hosted OAST collaborator (HTTP + DNS), and non-destructive validation that flips findings from detected to validated.

  • Self-hosted OAST for blind SSRF / XSS / RCE
  • Proxy history → ready-to-run engagement
  • False positives cut by safe confirmation
Prioritization

Ranked by exploit pressure

Corvex-RedOps Risk Priority blends CVSS with FIRST EPSS (exploit probability) and CISA KEV (known-exploited) into one transparent 0–100 score — every factor shown, with a remediation SLA and MTTR per finding. Offline-capable.

  • Transparent PRP — no black-box score
  • KEV / ransomware flags
  • Works air-gapped from a bundled feed
Analysis

Real findings from binaries

Upload an APK, IPA, Electron app or a directory graph export (JSON) and get findings with no external services — the gap most tools leave empty. Secrets are redacted; everything maps to MASVS / CWE / ATT&CK.

  • Native mobile & desktop static analysis
  • AD paths to Domain Admin, computed offline
  • SCA + SBOM, SAST, secret scanning
Deliverable

Client-ready reporting

Full technical and executive reports in HTML / PDF / DOCX — white-labeled, with the ATT&CK matrix, attack-path diagram, cloud findings and compliance mapping embedded. The report is a first-class output, not an afterthought.

  • OWASP / PCI-DSS / ISO 27001 / MITRE mapping
  • Per-tenant white-label branding
  • Local AI write-ups & FP verification (optional)
The pipeline

Point it at a target. Get a report.

Every module runs the same contract, so a web app and a domain controller are assessed with one methodology and land in one model.

→ 01

→ 02

→ 03

Validate

Non-destructive confirmation — detected becomes validated.

→ 04

Prioritize

→ 05

Report

Technical + executive, white-labeled, compliance-mapped.
